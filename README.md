# Te Ubicamos

Aplicación móvil desarrollada con Flutter para ayudar a las personas a ubicarse y encontrar información relevante desde un mismo lugar.

## Requisitos

- Flutter compatible con Dart 3.10.3 o superior.
- Android Studio o Xcode, según la plataforma objetivo.
- Configuración de Firebase para los servicios utilizados por la aplicación.

## Puesta en marcha

```bash
flutter pub get
flutter run
```

Para validar el proyecto antes de publicar cambios:

```bash
flutter analyze
flutter test
```

## Plataformas

El proyecto incluye configuración para Android, iOS, web, Windows, macOS y Linux. La aplicación está orientada principalmente a dispositivos móviles.
